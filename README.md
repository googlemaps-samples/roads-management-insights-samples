# Roads Management Insights Samples

This repository contains samples for Google Maps Platform Roads Management Insights.

## Contents

- [sample-app](./sample-app): A comprehensive demo application showcasing real-time and historical traffic data insights.
- [Route Registration Tool](./route-registration-tool): A interactive tool for creating Selected Routes.
